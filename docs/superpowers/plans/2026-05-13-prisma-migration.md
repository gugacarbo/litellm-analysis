# Prisma Migration: Replace Drizzle ORM with Prisma in litellm-repository

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Drizzle ORM with Prisma in `repositories/litellm-repository`, add a sync script that introspects the real LiteLLM database to keep the schema up-to-date, and migrate all consumers in `packages/analytics` to use Prisma.

**Architecture:** The `litellm-repository` package will use Prisma with the upstream LiteLLM `schema.prisma`. A `sync-schema` script will introspect the live database and regenerate the Prisma client. All 14 Drizzle query files in `packages/analytics` will be rewritten to use Prisma client queries.

**Tech Stack:** Prisma 6.x, @prisma/client, TypeScript, tsx (for scripts)

### Task 3: Create the sync-schema script

**Files:**
- Create: `repositories/litellm-repository/scripts/sync-schema.ts`

- [ ] **Step 1: Write the sync script**

This script connects to the live LiteLLM database, introspects the actual schema, and updates the local `schema.prisma`. It preserves the custom generator/output settings.

```typescript
import { execSync } from "node:child_process";
import { readFileSync, writeFileSync } from "node:fs";
import { resolve, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const __dirname = dirname(fileURLToPath(import.meta.url));
const rootDir = resolve(__dirname, "..");
const schemaPath = resolve(rootDir, "prisma", "schema.prisma");

const CUSTOM_HEADER = `datasource client {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
  output   = "../src/generated/prisma"
}
`;

function main() {
  console.log("🔍 Introspecting live LiteLLM database...");

  const rawOutput = execSync("npx prisma db pull --force --print", {
    cwd: rootDir,
    encoding: "utf-8",
  });

  const modelsSection = rawOutput
    .replace(/^datasource\s+\w+\s*\{[^}]*\}/ms, "")
    .replace(/^generator\s+\w+\s*\{[^}]*\}/ms, "")
    .trim();

  const fullSchema = `${CUSTOM_HEADER}\n${modelsSection}\n`;

  writeFileSync(schemaPath, fullSchema, "utf-8");
  console.log("✅ Schema updated from live database.");

  console.log("🔨 Regenerating Prisma client...");
  execSync("npx prisma generate", {
    cwd: rootDir,
    stdio: "inherit",
  });
  console.log("✅ Prisma client regenerated.");

  console.log("✅ Sync complete!");
}

main();
```

### Task 5: Rewrite helpers.ts

**Files:**
- Modify: `packages/analytics/src/queries/helpers.ts`

- [ ] **Step 1: Rewrite helpers for Prisma**

The current helpers build Drizzle `SQL` conditions. They need to be converted to Prisma `where` clause factories.

Key changes:
- `getSpendLogsTimeCondition(days)` → returns Prisma `SpendLogsWhereInput` filter
- `combineConditions()` → merges Prisma where conditions
- `normalizeDays()` → stays the same (pure logic)

```typescript
import type { Prisma } from "@lite-llm/litellm-repository/client";

export function normalizeDays(
  days: string | number | undefined,
  fallback: number,
): number {
  if (days === undefined || days === null) return fallback;
  const num = typeof days === "string" ? Number.parseInt(days, 10) : days;
  return Number.isNaN(num) || num < 0 ? fallback : num;
}

export function getSpendLogsTimeCondition(
  days: number,
): Prisma.LiteLLM_SpendLogsWhereInput {
  const cutoff = new Date();
  cutoff.setDate(cutoff.getDate() - days);
  return {
    startTime: { gte: cutoff },
  };
}

export function combineConditions(
  conditions: Prisma.LiteLLM_SpendLogsWhereInput[],
): Prisma.LiteLLM_SpendLogsWhereInput {
  const filtered = conditions.filter((c) => Object.keys(c).length > 0);
  if (filtered.length === 0) return {};
  if (filtered.length === 1) return filtered[0];
  return { AND: filtered };
}
```

### Task 6: Rewrite analytics-queries.ts

**Files:**
- Modify: `packages/analytics/src/queries/analytics-queries.ts`

- [ ] **Step 1: Rewrite query functions using Prisma**

Current file uses Drizzle's `litellmDb.select().from(schema.spendLogs)`. Replace with `prisma.liteLLM_SpendLogs.findMany()` / `prisma.liteLLM_SpendLogs.groupBy()`.

Key mapping:
- `litellmDb.select({...}).from(schema.spendLogs)` → `prisma.liteLLM_SpendLogs.findMany({ select: {...}, where: {...} })`
- `sql<number>\`SUM(...)\`.mapWith(Number)` → Prisma `aggregate()` or `groupBy()` with `_sum`, `_avg`, `_count`
- Complex SQL aggregations → `prisma.$queryRaw` or `prisma.$queryRawUnsafe`

Note: Some complex aggregations (percentiles, custom SQL expressions) will need `prisma.$queryRaw`. This is fine and equivalent to Drizzle's raw SQL support.
